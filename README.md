Exactly one funny line: a single joke that lands on a cold read, with no
setup notes and no explanation — the entry for make.fun's One Line, One
Laugh, where a judge model compares entries two at a time and the funniest
lines take the $2 prize (1st $1, 2nd $1).

> My GPS said 'recalculating' in the exact tone my mother uses when I say I'm fine.

The line was chosen by a local pairwise tournament over 14 fresh
one-liners, scored on the judge brief's five criteria in order: lands its
laugh on a first read, surprise turn, economy of words, freshness, clean
wording. It won 3 of 3 pairings in the final four. See `CANDIDATES.md` in
the build directory for the full table.

## Run it

```sh
python3 main.py
```

Writes the joke (81 characters, one line, no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Stdlib only,
deterministic: two runs produce byte-identical output.
